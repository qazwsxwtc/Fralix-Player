# Fralix-Player（frame (帧)+lix (流后缀)）
## 中文
Fralix‑Player（帧阅播放器），一款自研视频播放器。当前本项目只支持windows播放，且功能暂未完善，希望未来能逐步完善，支持多平台。并且能任意使用任何插件进行解码播放

## ENGLISH
Fralix‑Player, also known as 帧阅播放器，is a self‑developed video player. Currently, the project only supports playback on Windows with incomplete features. It is expected to be iteratively improved in the future to support multi‑platform deployment, as well as enabling arbitrary plug‑ins for decoding and playback.
